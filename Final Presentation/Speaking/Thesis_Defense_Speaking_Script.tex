\section*{Master Thesis Presentation}
\begin{itemize}
\item Good afternoon, my name is Heykel Khadhraoui. I developed a surface grinding controller for a seven-joint robot.
\item Normal pressing and compliant rotation allow contact to move the tool towards alignment. A separate experiment tests how the arm responds to disturbances.
\end{itemize}

\section*{Motivation}
\begin{itemize}
\item Grinding needs the tool face aligned with the physical surface. The configured normal comes from calibration against the plate, with residual uncertainty.
\item With a tilted tool, normal pressing creates a contact moment. Low rotational stiffness lets this moment turn the tool towards alignment.
\item Cartesian impedance makes position and rotation compliant. The desired orientation stays fixed while the rotational spring and damper remain active.
\end{itemize}

\section*{Contact demonstration}
\begin{itemize}
\item The video shows pickup, approach, contact, and the hold before grinding.
\item During the hold, I change the surface orientation. Normal pressing continues as contact moments rotate the tool.
\item The desired orientation stays fixed. This is a qualitative demonstration of compliant contact.
\end{itemize}

\section*{Cartesian pose}
\begin{itemize}
\item The end effector (EE) is the tool or gripper at the end of the arm. Its Cartesian pose describes position and rotation relative to the robot base frame.
\item Position uses x, y, and z, while roll, pitch, and yaw illustrate rotation. Together they give six degrees of freedom.
\item Forward kinematics calculates the pose from all seven joint angles, with \(p=p(q)\) for position. The controller uses a rotation matrix for orientation.
\end{itemize}

\section*{Cartesian impedance controller}
\begin{itemize}
\item Positional error points from measured to desired position. Rotational error uses a correction angle \(\phi\) and unit axis \(u\).
\item The sketch compares measured and desired tool orientations at one position. The axis points out of the page.
\item Stiffness produces force and moment. Damping opposes velocity differences.
\item Force and moment form a wrench. Its six-by-six stiffness and damping matrices have three-by-three blocks, with zero off-diagonal blocks here.
\item Before the point shift, the stiffness and damping matrices are diagonal in the surface frame.
\end{itemize}

\section*{Real-time control}
\begin{itemize}
\item The robot receives joint torques. We generate the Cartesian contribution from the wrench using the Jacobian transpose:
\[
\tau_{\mathrm{cart}}=J^\top(q)F
\]
\item The Jacobian maps joint velocities to the EE's linear and angular velocities. Model compensation and enabled null-space torques complete the command.
\item The measured pose feeds back into the control loop. The C++ controller uses libfranka and updates every millisecond.
\end{itemize}

\section*{Translation–rotation coupling}
\begin{itemize}
\item The tool centre point (TCP) is the controlled reference point attached to the EE. The centre of compliance (CoC) at \(p_c\) is a virtual reference for stiffness and damping.
\item Moving the CoC changes how position and rotation errors generate force and moment. Its displacement from the TCP is \(r_c=p_c-p_{\mathrm{TCP}}\).
\item The full matrix equation uses the same force--moment column and position--rotation error column as the Cartesian controller. The \(A^\top\) and \(A\) transformations shift both stiffness and damping to the TCP.
\item The underbraces identify the TCP stiffness and damping matrices. Their off-diagonal blocks couple translation and rotation.
\item The error transforms as \(e_c=Ae\), and the wrench transforms as \(F_{\mathrm{TCP}}=A^\top F_c\). These point-shift relations use the small-rotation model.
\end{itemize}

\section*{Centre of compliance (CoC)}
\begin{itemize}
\item Shifting the CoC can change both the commanded force and moment. The shifted controller's force acts as if applied at \(p_c\):

\item The added moment can support or oppose alignment. For the same force, reversing the displacement reverses this contribution.
\item With the CoC at the TCP, the added contribution vanishes. The rotational spring and damper still produce \(m_R\).
\end{itemize}

\section*{Contact experiment}
\begin{itemize}
\item The process goes from tool orientation and surface approach to contact establishment, then grinding. These experiments evaluate the five-second contact-establishment phase.
\item Low normal stiffness allows compliant pressing, while higher tangential stiffness resists sideways movement. Rotational stiffness is higher about the normal and lower about the surface tangents.
\item The position reference advances into the surface to generate pressing force. The desired orientation stays at its entry value, so contact moments drive the rotation.
\end{itemize}

\section*{Normal-force plausibility assessment}
\begin{itemize}
\item I manually push the tool about 20 millimetres along the surface normal, with the CoC at the TCP. This checks the spring-force prediction with the desired pose fixed.
\item The stiffness is 1000 newtons per metre and the measured position-error change is \(-19.65\) millimetres. Their product gives the spring-force prediction:
\[
F_{n,\mathrm{qs}}=(1000\,\mathrm{N/m})\cdot(-19.65\times10^{-3}\,\mathrm{m})=-19.65\,\mathrm{N}
\]
\item In the shaded stationary interval, the commanded mean is \(-19.64\) newtons, only 0.05 percent from the calculation. The robot's model estimate is \(-22.29\) newtons, 13.50 percent from the command.
\end{itemize}

\section*{Moment plausibility assessment}
\begin{itemize}
\item I manually rotate the tool about surface tangent one while keeping the normal push. This checks the spring-moment prediction with the desired pose fixed and CoC at the TCP.
\item The measured rotational error changes by \(6.57^\circ\) relative to the loaded baseline. With a stiffness of 15 newton metres per radian, converting this change to radians gives:
\[
M_{t_1,\mathrm{qs}}=(15\,\mathrm{N\,m/rad})\cdot(6.57\cdot\frac{\pi}{180}\,\mathrm{rad})\approx1.72\,\mathrm{N\,m}
\]
\item In the shaded stationary interval, the commanded mean matches the calculated 1.72 newton metres. The robot's model estimate is 1.85 newton metres, 7.75 percent from the command.
\end{itemize}

\section*{Commanded and estimated wrench}
\begin{itemize}
\item A separate contact-establishment trial compares commanded force and moment with the robot's model estimates. The CoC is at the TCP.
\item During the final stationary interval, mean differences are 2.32 percent for force and 4.87 percent for moment. The curves differ more during motion.
\end{itemize}

\section*{Baseline angular error}
\begin{itemize}
\item With the CoC at the TCP, entry offsets of \(0.69^\circ\), \(+9.31^\circ\), and \(-9.41^\circ\) gave angular errors of \(1.65^\circ\), \(1.75^\circ\), and \(1.41^\circ\).
\item The error magnitude decreased for both larger entry tilts, and the negative entry error changed sign. The nominal-zero condition increased from \(0.69^\circ\) to \(1.65^\circ\).
\item The bars show three-trial means, with one sample standard deviation. These are first-tangent components relative to the calibrated surface, calculated from recorded endpoints at \(0.01^\circ\) precision.
\end{itemize}

\section*{Effect of rotational stiffness}
\begin{itemize}
\item Increasing rotational stiffness from 5 to 50 newton metres per radian increased the angular error from \(1.75^\circ\) to \(6.58^\circ\). The stiffer rotational spring allowed less contact-induced correction.
\end{itemize}

\section*{Effect of CoC position}
\begin{itemize}
\item The plot covers minus 80 to plus 80 millimetres, with three repetitions per setting. For positive entry tilt, the smallest tested angular error was \(1.17^\circ\) at plus 80 millimetres. At minus 80 millimetres, \(9.35^\circ\) remained.
\item For negative entry tilt, the smallest angular error magnitude was \(0.94^\circ\) at plus 10 millimetres. At minus 80 millimetres, the error component crossed zero and ended at \(+2.23^\circ\).
\item CoC displacement changes the remaining error component and can reverse its direction. Greater rotation therefore does not always give a smaller angular error.
\end{itemize}

\section*{Null-space controller}
\begin{itemize}
\item The contact results are complete. The separate null-space study concerns the arm's redundant joint motion. At full Jacobian rank, seven joints leave one null-space direction with zero instantaneous EE motion.
\item Damping reduces null-space motion by opposing redundant joint velocity.
\item Conditioning chooses between two local null-space directions and drives towards the one with the larger minimum singular value. It can initiate joint motion. At a singularity, the EE loses an instantaneous motion direction. Near it, some EE motions require very large joint velocities. A larger minimum singular value indicates better local conditioning under the same Jacobian convention.
\end{itemize}

\section*{Null-space experiment}
\begin{itemize}
\item The desired position and orientation stay fixed while joint torques apply a repeatable disturbance. This is equivalent to a virtual 20-newton point force on link three.
\item We compare no null-space torque, damping, and two conditioning settings, with three trials each. Conditioning is active before and during the disturbance.
\item We compare cumulative joint motion, minimum singular value, and net joint motion.
\end{itemize}

\begin{itemize}
\item Cumulative joint motion, \(E_N\), adds projected joint movement in both directions. These degrees describe arm motion, not rotation of the tool.
\item Damping reduces it from \(7.60^\circ\) to \(5.69^\circ\), about 25.1 percent. Conditioning gives \(0.29^\circ\) at \(k_\sigma=1.5\) and \(1.69^\circ\) at \(k_\sigma=2\).
\item Curves show three-trial means over the displayed four-second interval. Shading shows one sample standard deviation.
\end{itemize}

\section*{Jacobian conditioning}
\begin{itemize}
\item A smaller minimum singular value means some tool motions require larger joint velocities. Zero means the EE loses an instantaneous motion direction.
\item It falls with no null-space torque and with damping. Both conditioning settings keep it nearly constant during the disturbance.
\item Curves show three-trial means over the same four-second interval and use the same Jacobian convention. Shading shows one sample standard deviation.
\end{itemize}

\section*{Net joint motion}
\begin{itemize}
\item Net joint motion measures projected joint movement remaining after opposite motions cancel. It is \(7.52^\circ\) without null-space torque and \(5.61^\circ\) with damping.
\item Mean net joint motion values with conditioning are only \(1.5\times10^{-2}\,{}^\circ\) and \(-1.1\times10^{-2}\,{}^\circ\). Conditioning counters the disturbance in the tested direction.
\item Cumulative joint motion values are \(0.29^\circ\) and \(1.69^\circ\). The larger value is consistent with more back-and-forth motion despite similarly small net joint motion.
\end{itemize}

\section*{Conclusion}
\begin{itemize}
\item Contact reduced angular error for both larger entry tilts while the desired orientation stayed fixed. The error is relative to the calibrated surface and retains calibration and tool-mount uncertainty.
\item Higher rotational stiffness increased angular error from \(1.75^\circ\) to \(6.58^\circ\).
\item CoC displacement changes angular error and can carry it through zero. At the TCP, the added moment vanishes while the rotational spring and damper remain active.
\item Damping reduced arm motion, and conditioning countered the tested disturbance direction. Nearly zero net joint motion coexisted with back-and-forth motion.
\item Future work is a more rigid tool mount and adaptive CoC selection. After alignment, the adaptive CoC should return to the TCP.
\end{itemize}

\section*{Null-space torques and projector}
\begin{itemize}
\item The kinematic projector selects null-space torque directions. It uses the Jacobian \mbox{pseudoinverse \(J^+\)}.
\[
N_\tau=I_7-J^\top J^{+\top}
\]
\item Damping and conditioning add to give the total null-space torque.
\[
\tau_{\mathrm{null}}=\tau_d+\tau_\sigma
\]
\item Damping opposes projected joint velocity and is zero at rest. \(d_{\mathrm{null}}\) is the damping coefficient.
\[
\tau_d=-d_{\mathrm{null}}N_\tau\dot q
\]
\item Conditioning probes both directions along the unit null-space vector \(v_7\). It chooses the direction with the larger minimum singular value.
\[
\tau_\sigma=k_\sigma N_\tau(s_\sigma v_7)
\]
\item The selector \(s_\sigma\) is \(+1\) or \(-1\), and zero within the deadband. \(k_\sigma\) sets the torque magnitude, which can be nonzero at rest.
\end{itemize}

\section*{Disturbance demonstration}
\begin{itemize}
\item The controller holds the tool pose throughout the video. Without null-space torque, the disturbance moves the arm.
\item Damping opposes the joint motion.
\item Conditioning actively changes the arm configuration and can initiate motion. The tool stays approximately in place.
\end{itemize}
